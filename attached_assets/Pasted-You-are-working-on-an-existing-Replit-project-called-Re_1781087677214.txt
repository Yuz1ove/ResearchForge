You are working on an existing Replit project called Report Factory AI.

You are a senior frontend engineer, product manager, and AI report-generator designer.

Your task is to improve the existing app.
Do not rebuild the entire project.
Do not remove existing features.
Do not change the overall visual identity unless necessary.
Keep all user-facing website text in Traditional Chinese.

The goal is to upgrade the current app from a simple template-based report outline generator into a more useful multi-style, multi-mode report generator for students, researchers, and project creators.

⸻

1. Current app context

The current website already has:

* A homepage hero section
* “開始生成報告” button
* “查看報告格式” button
* Report topic input
* Report type select
* Report style select
* Report length select
* Generate report button
* Loading state
* Generated report result card
* Sections such as summary, research background, research purpose, research questions, research hypothesis, literature review outline, research method, suggested charts, suggested images, research limitations, conclusion draft
* Copy report button
* Download Markdown button
* Regenerate button
* Clear content button
* Report quality checklist

Please keep all of the above features and improve them.

⸻

2. Main problems to fix

The current app has these issues:

1. When the user enters a very short topic, such as “鵝”, “AI”, “咖啡”, or “手機”, the generated content is too generic.
2. The app often generates vague sentences such as:
    * “X 是近年來受到廣泛關注的重要議題。”
    * “本研究具有重要意義。”
    * “未來值得深入探討。”
3. Different topics are currently using almost the same template.
4. The report result feels more like a report outline draft, not a real editable report.
5. The form does not collect enough information to generate high-quality reports.
6. Mobile layout needs improvement, especially spacing near the top when using Replit preview.
7. The app should avoid fake citations or fake sources.

⸻

3. Important language rule

All code comments, variable names, and internal logic may be in English.

However, all text visible to users in the website must be in Traditional Chinese, including:

* Labels
* Buttons
* Placeholder text
* Generated report headings
* Warning messages
* Quality checklist items
* Completion status cards
* Topic expansion suggestions

Do not translate the website UI into English.

* 魚類

Suggested structure:

1. 主題基本介紹
2. 生物分類與基本特徵
3. 生活習性
4. 棲息環境
5. 與人類生活的關係
6. 經濟、文化或生態價值
7. 相關問題與討論
8. 結論

If the topic is “鵝”, the generated content should mention concrete details such as:

* 鵝是常見家禽
* 具有群居性
* 警覺性高
* 可作為肉品、蛋品、羽絨來源
* 與農業、畜牧業、人類飲食有關
* 可討論飼養管理、動物福利、疾病防治或產業價值

Avoid writing:

「鵝是近年來受到廣泛關注的重要議題。」

Instead, write something more specific, such as:

「鵝是人類長期飼養的家禽之一，常見於農業與畜牧環境中。牠不只具有食用價值，也因警覺性高、群居性明顯，而在人類生活與農村文化中具有特殊角色。」
