DEVELOPMENT CONSTRAINTS

IMPORTANT:

This project operates under limited AI development credits.

You MUST optimize for:

* Minimal code changes
* Minimal agent actions
* Minimal file modifications
* Maximum feature delivery

⸻

BEFORE MODIFYING ANY FILE

Always ask:

Can this feature be implemented by extending existing code?

If YES:

DO NOT rewrite.

Extend.

⸻

ALWAYS PREFER

1. Editing existing files
2. Adding helper functions
3. Adding new modules
4. Reusing components
5. Incremental improvements

⸻

NEVER DO

Without explicit approval:

* Rewrite entire pages
* Rewrite entire systems
* Replace architecture
* Migrate frameworks
* Rebuild existing components
* Perform large-scale refactoring

⸻

ONLY REWRITE WHEN

1. Existing implementation is broken
2. Existing implementation blocks required features
3. User explicitly requests rewrite
