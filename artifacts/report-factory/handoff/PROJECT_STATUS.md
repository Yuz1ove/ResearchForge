# Report Factory AI — 專案狀態（PROJECT_STATUS）

> 版本：V3（A+B+C+D+E+F 完成）
> 性質：繁體中文 AI 報告「規劃」引擎。目前為本地模擬生成（無外部模型）。
> 核心原則：不杜撰事實與引用，未證實處以〔…〕或「資料來源待補」標示。

## 目前可用功能

### 1. 主題輸入與擴寫
- 報告主題輸入框，含「幫我擴寫主題」可將簡短主題擴寫成完整題目。
- 簡短主題會提示補充建議。

### 2. AI 領域判定 + 手動覆寫（C）
- 輸入主題後即時顯示「AI 判定領域」。
- 可用下拉手動覆寫領域（自動偵測 / 11 個領域）。

### 3. 領域專屬框架（A）
支援以下領域，各自有不同的章節骨架、研究問題、文獻方向、圖表、表格與資料需求：
- 生物／動物、科學實驗、社會議題、歷史／地理／公民、讀書心得、
  商業／產品分析、AI／網站／程式專案、醫療／長照／社工／心理、
  食品／飲食文化、化學／化工、一般學校報告。

### 4. 生成模式（含 Eric 研究模式 / B + F）
- 報告架構、完整報告、**Eric 研究模式**、簡報大綱、資料需求表、圖表與圖片建議。
- Eric 研究模式輸出研究規劃藍圖：研究領域與意圖 → 研究問題 → 研究目的 →
  研究假設 → 文獻探討方向 → 建議研究架構 → 建議圖表 → 建議資料表格 →
  建議流程圖 → 報告初稿大綱。

### 5. 學術程度（C）
- 國中／高中／大學／專業，作為單一事實來源，自動推導讀者對象與報告目的。

### 6. 匯出中心（D）
- 文件：Word（DOCX，含封面／目錄／頁首頁尾）、PDF（列印）、Markdown、TXT、複製文字。
- 規劃與交接：研究藍圖（Markdown）、AI 提示包（可貼入其他 AI）、JSON、匯出專案狀態。
