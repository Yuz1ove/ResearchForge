# Day 25 Outline｜FORMAL、LIMITED、BLOCKED：不是分數，而是三種可說話的邊界

- **Hook**：同一篇 abstract 可以很有用，卻不能支撐全文方法與偏差分析。
- **Thesis**：admission class 應決定允許的 claim surface，不是把資料打成高、中、低分後任意使用。
- **Narrative**：field statuses → Study Fact admission → canonical access state → output class。
- **Technical core**：FORMAL requires qualifying content/facts/provenance；LIMITED carries explicit restrictions；BLOCKED stays outside Writer。
- **Table**：class／可用內容／禁止主張／必要 disclosure。
- **Transferable lesson**：confidence score 不能代替 permission model。
- **Fact boundary**：abstract-only可維持 LIMITED product behavior，不能走 legacy path 變 FORMAL。
- **Ending**：如果不同模組各自算 class，仍會出現三種真相。Day 26。
