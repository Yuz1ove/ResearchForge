# Day 15 Outline｜Prototype 變成工程專案的那一刻：不是檔案變多，而是失敗可以被定位

- **Hook**：同一個綠色 test badge 可能只證明 parser contract，完全沒碰 live full text。
- **Thesis**：成熟不是測試數變大，而是 engineering、live content、export、render、security、deployment gate 不再互相冒充。
- **Narrative**：generator hotspot → shared schemas/tests → 8/13 vertical slice → later fail-closed acceptance layers。
- **Technical core**：focused tests、full regression、live cohort、canonical export、visual QA、deployment 分開記錄。
- **Table**：gate／回答的問題／不能證明什麼。
- **Transferable lesson**：每個 PASS 都要附 scope；第一個 failing layer 比總 verdict 更能指導修復。
- **Fact boundary**：不在 public article dump exact test counts，除非用一組對比說明 scope。
- **Ending**：下一個最容易被「有就算」的 gate，是 citation。Day 16。
