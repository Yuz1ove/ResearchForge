# Day 19 Outline｜研究互相矛盾時，系統不該急著選邊站

- **Hook**：兩篇研究一正一負，不一定互相否定；它們可能測了不同 outcome 或不同 population。
- **Thesis**：先判 comparability，再描述 heterogeneity；只有在可比較條件成立時談 conflict。
- **Narrative**：facts → four comparability levels → study-difference matrix → contradiction status。
- **Technical core**：SAME、DIFFERENT、PARTIALLY_COMPARABLE、UNKNOWN／NOT_REPORTED；不可跨 metric pooling。
- **Visual**：study × field matrix，缺值保持狀態。
- **Transferable lesson**：knowledge system 不應把 disagreement 壓成 majority vote。
- **Fact boundary**：不得把 missing/missing 寫成 SAME，不推論未支持因果。
- **Ending**：即使比較完成，誰有權把結果寫進正文？Day 20。
