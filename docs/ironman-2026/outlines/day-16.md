# Day 16 Outline｜引用不是句尾那一對括號

- **Hook**：參考資料表完整、正文也有 marker，仍可能把 A 的結果綁到 B。
- **Thesis**：citation correctness 是 claim → evidence → source → reader marker 的閉合，不是 bibliography presence。
- **Narrative**：citation foundation → sentence binding → internal provenance/reader projection → publication layout。
- **Technical core**：stable citation registry、orphan/missing/mapping checks、internal ID 不外露、cross-format anchor。
- **Code**：簡化 citation registry；顯示 marker 與 evidence owner 分離。
- **Transferable lesson**：展示層可以壓縮引用，不能改變 sentence-level ownership。
- **Fact boundary**：Case A publication READY 不等於 Case B 或新題 READY。
- **Ending**：每句都有引用，整篇仍可能只是逐篇摘要；Day 17 談 synthesis。
