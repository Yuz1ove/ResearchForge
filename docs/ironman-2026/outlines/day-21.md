# Day 21 Outline｜一份可信報告，最後還可能死在 DOCX 裡

- **Hook**：canonical 內容正確，到了 DOCX 卻可能出現缺字、孤兒標題、斷裂表格或 citation drift。
- **Thesis**：publication pipeline 是 correctness layer；Preview、Markdown、DOCX、PDF 必須投影同一 canonical document。
- **Narrative**：writer output → formal document → reader citations → layout fixes → all-page visual QA。
- **Technical core**：CJK font、heading/page breaks、editable table、figure eligibility、cross-format anchors。
- **Visual**：canonical document 向四種 format 投影，驗證點回連 canonical。
- **Transferable lesson**：export success 是檔案存在；publication acceptance 是內容與 render 都可讀且閉合。
- **Fact boundary**：Case A 通過，Case B 因 supported content 不足未匯出。
- **Ending**：一個成功出版案例接著遇到三個新題全失敗。Day 22。
