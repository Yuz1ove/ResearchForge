# Day 18 Outline｜Atomic Study Facts：先把論文拆成可以比較的最小單位

- **Hook**：「研究顯示有效」無法比較，因為 population、design、outcome、estimate 全被藏在一句裡。
- **Thesis**：先建立 type-aware、provenance-bound Study Fact envelope，再允許 cross-study claims。
- **Narrative**：generic claim cards failed → schema fields → exact locator → LIMITED/FORMAL admission。
- **Technical core**：study type、population、intervention/exposure、comparator、outcome、direction、magnitude、uncertainty、follow-up、limitations。
- **Code**：PRESENT/NOT_REPORTED/UNKNOWN/NOT_APPLICABLE 的 union type。
- **Transferable lesson**：missingness policy 是知識系統的一級功能。
- **Fact boundary**：fresh V2 只有 7/10 LIMITED、0/10 FORMAL；replay recovered facts 不當 live。
- **Ending**：欄位對齊後才看得見異質性與矛盾。Day 19。
