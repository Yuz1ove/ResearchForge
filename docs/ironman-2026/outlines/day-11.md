# Day 11 Outline｜一個研究問題，不能只靠一堆「相關」論文回答

- **Hook**：來源卡已經很多，真正對應到 research question 的 evidence column 卻仍是空的。
- **Thesis**：研究問題要拆成可檢查的 facets／subquestions；coverage 是「哪些問題被哪些直接事實回答」，不是來源數。
- **Narrative**：早期 section hints → topic facets → evidence coverage → evidence gap planner。
- **Technical core**：population、exposure/intervention、comparator、outcome、context；card-to-RQ mapping；covered/partial/unknown。
- **Diagram**：RQ tree → evidence matrix → gap list → targeted query。
- **Transferable lesson**：RAG 的 retrieval completeness 應以 task coverage 衡量，不以 chunk count 衡量。
- **Fact boundary**：不得宣稱 evidence-gap planner 已讓十題 generalization 過關；V3 live 仍為 PARTIAL。
- **Ending**：即使 gap 找對，provider 仍可能 timeout 或 rate-limit；Day 12 進入 degraded runtime。
