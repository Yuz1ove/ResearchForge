# Day 29 Outline｜合法拿到全文，比我想像中更像一套文件鑑識系統

- **Hook**：一個 `.pdf` URL 可能回 HTML；一份可讀 PDF 可能是錯文章、掃描檔或 supplement。
- **Thesis**：full-text acquisition 是 route、policy、format、identity、structure 與 provenance 的聯合判定。
- **Narrative**：legal OA routes → payload classification → landing follow → parser dispatch → identity/qualification → residual Pareto。
- **Technical core**：JATS/TEI/HTML/PDF/OCR；magic bytes；stable repository ID；VOR/preprint/repository manifestation；rights/access。
- **Diagram**：candidate route → fetch → sniff → materialize → identity → qualify → canonical artifact。
- **Transferable lesson**：不要用字元長度或 HTTP status 取代 semantic artifact qualification。
- **Fact boundary**：不描述任何 paywall/auth/CAPTCHA/robots bypass；live coverage仍低。
- **Ending**：最後一天不畫完成線，而回答一個可靠系統如何說「不知道」。
