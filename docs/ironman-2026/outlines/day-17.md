# Day 17 Outline｜為什麼把十篇摘要接起來，仍然不叫 Synthesis

- **Hook**：一段一篇、句尾一個 citation，形式很學術，閱讀後卻沒有跨研究答案。
- **Thesis**：synthesis 要以 concept／claim 為主軸比較來源，不以 source order 排列摘要。
- **Narrative**：source stitching symptom → Atomic Facts/Claim Graph → teach-back → academic reconstruction → entailment failure。
- **Technical core**：direct result、shared direction、difference、mechanism、boundary、gap；source-order echo gate。
- **Diagram**：papers → atomic claims → graph → themes → narrative。
- **Transferable lesson**：RAG 的 synthesis quality 不等於 retrieval completeness；需要 cross-document relations。
- **Fact boundary**：8/13 real model run被阻擋，不能用 deterministic benchmark 代替 live success。
- **Ending**：要比較研究，先把每篇拆成共同欄位。Day 18。
