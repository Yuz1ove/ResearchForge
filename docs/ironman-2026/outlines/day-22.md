# Day 22 Outline｜一個成功案例，最容易讓人高估整套系統

- **Hook**：Case A 的 PDF/DOCX 全部通過；換三個題目，0 個通過 canonical export。
- **Thesis**：gold case 證明一條路可行，不證明 system generalizes。
- **Narrative**：accepted publication → three unseen topics → three different first failures → no export。
- **Technical core**：new-topic fixed cohort、no resampling、Writer gate vs canonical gate、NO-EXPORT artifact。
- **Table**：題目／first weak layer／Writer 是否跑／export。
- **Transferable lesson**：generalization test 要固定題組、門檻與 rerun policy，避免挑有利樣本。
- **Fact boundary**：不把 3-topic result 外推成所有領域，也不把 Case A 降格成失敗。
- **Ending**：第一個驚訝是「有很多來源，direct study 卻是零」。Day 23。
