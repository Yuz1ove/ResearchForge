# Day 23 Outline｜搜尋結果很多，為什麼 Direct Study 還是零？

- **Hook**：candidate、accepted source、direct study 三個數字可以同時很不一樣。
- **Thesis**：direct study 是能直接回答研究問題的 empirical unit，不是任何高度相關來源。
- **Narrative**：0/10 ingestion → study-type classification → relevance false negative → bounded zero-direct cascade。
- **Technical core**：review vs empirical study、population/exposure/outcome fit、strict identity dedupe、early stop。
- **Diagram**：candidate → relevant → direct study → content-accessed → admitted fact。
- **Transferable lesson**：retrieval 系統需明確定義「成功單位」，否則 raw recall 會掩蓋 downstream zero。
- **Fact boundary**：V3 direct-study 9/10 仍只有 full-text 2/10，不能宣稱問題解完。
- **Ending**：找到 direct study 後，DOI 仍不是文件。Day 24。
