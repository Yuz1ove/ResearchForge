# Quality Rules

The report judge is deterministic and rule-based.

## Readiness

- `insufficient`: fewer than 3 accepted sources or too little evidence.
- `preliminary`: enough for a rough draft, but not a formal report.
- `usable`: acceptable working draft with grounded sections.
- `strong`: broad enough source base for a fuller report.

## Warnings

Flag these conditions:

- citations that do not exist in accepted sources
- sections with no evidence links
- unsupported claim language without grounding
- causal claims built from weak correlation
- topic drift away from the research question
- overreliance on a single source
- source counts below the current depth target

## Depth Thresholds

- `quick`: proceed with a short draft, but warn when evidence is thin.
- `standard`: prefer 6-10 accepted sources.
- `deep`: prefer 10+ accepted sources and stricter critique.

## Section Expectations

Each main section should know:

- which evidence cards support it
- which citations it uses
- which warnings were triggered
